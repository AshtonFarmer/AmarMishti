This is a handmade birthday website created for Tanima.

It begins with a glowing birthday page, then opens into a
multiverse-style experience with cars, constellations, music,
a memory video, hidden jokes, secret pages, rain, flowers,
and a duck mini-game.

The goal is to feel:
✓ romantic
✓ funny
✓ cinematic
✓ personal
✓ interactive
✓ unforgettable
